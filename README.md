# Gesture-controlled-rc-car-with-object-detection-.
Developed an Arduino-based gesture-controlled robotic car with ultrasonic object detection, integrating embedded firmware, sensor interfacing, wireless communication, and motor control. The transmitter uses an MPU6050 inertial measurement unit (IMU) to detect hand movements and an HC-05 Bluetooth module to transmit control commands to the receiver. The receiver, built around an Arduino Uno, processes incoming commands and drives two DC motors through an L298N motor driver for directional control. An HC-SR04 ultrasonic sensor measures the distance to nearby obstacles, enabling obstacle detection and supporting collision-avoidance logic. This project demonstrates practical implementation of embedded C/C++ programming, UART-based Bluetooth communication, real-time sensor data processing, GPIO interfacing, and hardware–firmware integration.
